# Ключи и маршрутизация

Настройки доступны в [локальной панели](http://127.0.0.1:1608/admin) после [первой установки](../START-HERE.md). Альтернативный способ — постоянные строковые глобальные переменные Streamer.bot. Заполняй ключи только используемых сервисов.

## Где получить ключи

| Сервис | Где создать | Переменная и формат |
| --- | --- | --- |
| OpenRouter | [Keys](https://openrouter.ai/settings/keys) | `OpenRouterKey`: сам ключ, без `Bearer` |
| Fireworks | [API keys](https://fireworks.ai/account/api-keys) | `FireworksKey`: сам ключ |
| fal.ai | [Dashboard → Keys](https://fal.ai/dashboard/keys) | `FalApiKey`: значение ключа целиком, без `Key ` |
| Inworld | [Portal](https://platform.inworld.ai/), API credentials | `InworldTTSAuth`: полный заголовок `Basic …`, скопированный из кабинета; повторно base64 не кодировать |
| Fish Audio | [API keys](https://fish.audio/app/api-keys) | `FishAudioApiKey`: сам ключ; `FishAudioVoiceRefId`: ID доступной голосовой модели |
| ElevenLabs | [Developers](https://elevenlabs.io/app/developers/api-keys) | `ElevenLabsKey`: API key с разрешением Text to Speech; `ElevenLabsVoiceId`: ID из карточки голоса / My Voices |
| NTTS | [Сервис и документация](https://ntts.fdev.team/docs) | `NttsApiKey`: токен своего аккаунта; работоспособность сервиса зависит от его доступности |
| MemeAlerts | [Поддержка](https://memealerts.com/support) | Приложение регистрирует поддержка. `clientId` → `maClientId`, `clientSecret` → `maClientSecret`; [порядок подключения](https://github.com/Kiwunaka/streamer.bot-donationAlerts/blob/main/docs/MEMEALERTS.md) |

Ключи остаются в постоянных глобальных переменных Streamer.bot. Не публикуй его конфиги/экспорты с заполненными секретами. WebSocket держи на loopback с Authentication; панель требует пароль и не записывает его или API-ключи в localStorage.

## TTS: Fish Audio, ElevenLabs, Inworld, NTTS

`TtsProviderPrimary`, `TtsProviderSecondary`, `TtsProviderTertiary` задают один маршрут для `TTS` и AI-донатов. Значения: `fish`, `elevenlabs`, `inworld`, `ntts`, `none`. Повторяющийся провайдер вызывается один раз. При ошибке или отсутствии ключа используется следующий; скрытого добавления других сервисов нет.

Пример:

```text
TtsProviderPrimary=fish
TtsProviderSecondary=elevenlabs
TtsProviderTertiary=none
FishAudioModel=s2.1-pro
FishAudioVoiceRefId=ID_ТВОЕГО_ГОЛОСА
FishAudioFormat=mp3
ElevenLabsModel=eleven_multilingual_v2
ElevenLabsVoiceId=ID_ТВОЕГО_ГОЛОСА
```

Fish использует `POST /v1/tts`, Bearer token и заголовок `model`. Поддержаны MP3, WAV, Opus; `s2.1-pro-free` выбирай только при доступе к соответствующему тарифу. ElevenLabs использует `POST /v1/text-to-speech/{voice_id}` с `xi-api-key`, возвращает MP3. Возможность использовать голос зависит от твоего аккаунта.

Inworld: `InworldModelId=inworld-tts-2`, голос из своего кабинета, `InworldAudioEncoding=LINEAR16` или WAV/MP3/OGG_OPUS/FLAC, частота `InworldSampleRateHertz`, скорость `InworldSpeakingRate=0.5..1.5`. Нестриминговый API принимает максимум 2000 UTF-16 символов; длинный текст передаётся следующему TTS, если он настроен. Raw PCM не используется для прямого проигрывания.

Для каждой из персон `Skuf`, `Toxic`, `UwU`, `Mistress` можно задать:

```text
Persona_Skuf_FishRefId=...
Persona_Skuf_Voice=...                 # ElevenLabs
Persona_Skuf_InworldVoiceId=...
```

Приоритет — голос персоны, затем общий voice ID. Меняй эти поля в разделе «Персоны». Смена персоны сохраняет твои промпты и настроенные голоса. Прежние `FishAudioEnabled` / `NttsMixPct` больше не управляют маршрутом: отключай сервис значением `none` в трёх позициях.

## Картинки и fal.ai

- `ImageGenerationProvider=fal`: картинки за баллы через очередь fal. `FalImageModel=fal-ai/flux/schnell` или `fal-ai/flux/dev`. Один квадратный JPEG, safety checker включён. Поддержаны эти два FLUX endpoint; произвольным моделям fal нужна другая схема запроса.
- `ImageGenerationProvider=fireworks`: `ImageGenerationModel=accounts/fireworks/models/flux-kontext-max` либо `.../flux-kontext-pro`. URL workflow строится из модели; старый `ImageGenerationWorkflowUrl` не применяется.
- `DonationImageProvider=fal`, `openrouter` или `none`. Для OpenRouter настрой `DonationImageModel` на модель с генерацией изображений. `none` сохраняет текст и озвучку доната.
- `ImageRefineProvider` и `ImageRefineModel` — отдельное уточнение промпта. `ImageRefinePrompt` пусто = встроенная инструкция, которая сохраняет идею зрителя и возвращает один английский промпт.
- `ImageReactionEnabled` включает дополнительный запрос к модели со зрением; провайдер и модель задаются отдельно.
- `ImageShareToChat=false` по умолчанию. Включение отправляет картинку на внешний uguu.se и публикует ссылку в чат.

Генерация отправляется один раз. fal возвращает `request_id`, он пишется в журнал; клиент ждёт результат до 90 секунд и запрашивает отмену незавершённого задания. Отмена не гарантирует возврат оплаты, если обработка уже началась. После таймаута проверь задание в кабинете перед новым запуском. Ключ не передаётся при скачивании изображения с CDN.

## Текст и промпты

Общий `LlmProvider=openrouter/fireworks`; конкретный модуль может переопределить его через `ChatBotProvider`, `ModProvider`, `ModResponseProvider`, `OracleProvider`, `DonationProvider`, `StreamRecapProvider`. Пустое значение использует общий выбор. Модель указывается отдельно: `ChatBotModel`, `ModModel`, `ModResponseModel`, `OracleModel`, `DonationModel`, `StreamRecapModel`. ID должен принадлежать выбранному провайдеру; Fireworks обычно использует `accounts/fireworks/models/...`.

На 18.10.2026 в публичном каталоге OpenRouter проверены `google/gemini-2.5-flash-lite` для короткого текста, `google/gemini-2.5-flash` для зрения и `google/gemini-2.5-flash-image` для картинок. Это значения по умолчанию, доступ и цены проверяй в своём аккаунте. `InitGlobals` с `force=false` заменяет только два удалённых ID: `xiaomi/mimo-v2-flash` и `google/gemini-2.0-flash-001`; остальные заданные модели сохраняет.

Промпт чата — `ChatBotSystemPrompt`, ответ модератора — `ModResponsePrompt`, характер и стиль — `Persona_<Имя>_System` / `_Style`. Донаты требуют JSON со схемой из обработчика; его служебная часть добавляется к характеру автоматически. Реплики для TTS — обычный текст, без выдуманных тегов эффектов. Сообщения, имена и история зрителей передаются как данные, а не инструкции сменить роль.

Генератор вступлений: `python generate_intros.py --persona UwU` только печатает промпт. Для платного запроса нужны зависимости из соседнего `requirements.txt`, переменная окружения `OPENROUTER_API_KEY` и `--generate`; для замены существующей картинки — `--overwrite`. После замены скопируй PNG в `assets` плагина.
