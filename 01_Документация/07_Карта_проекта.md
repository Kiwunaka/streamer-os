# Карта проекта и разбор наработок

## Устройство системы

```text
Триггеры / чат / награды / донаты
              ↓
      Действия Streamer.bot
       ↙              ↘
AI / TTS API       POST /events
                       ↓
        Нативный OBS-плагин + очередь
                       ↓
        visual_runtime.html в OBS
```

Основные части связаны через постоянные глобальные переменные Streamer.bot и HTTP runtime. `SharedCore` содержит модели состояния, контракты и очередь, но многие inline-действия пока самостоятельно читают и записывают JSON. Это набор связанных действий, а не один исполняемый C#-проект.

## Что перенесено

Сохранены собственные исходники, документация, изображения и аудио вступлений, виджеты, userscript, локализации и скрипты сборки. Структура трёх исходных каталогов сохранена. Две версии музыкальных виджетов различаются, поэтому сохранены обе.

Не включены дерево исходников OBS с зависимостями и встроенными Git-репозиториями, инструменты/установщики, каталоги сборки и готовые EXE/DLL. Это внешние зависимости и результаты сборки. Рабочий Google service-account ключ из исходной папки оставлен локально и добавлен в `.gitignore`.

## Исправления при переносе

- Ссылки в документации переведены с абсолютной папки автора на относительные пути.
- Путь TTS-кэша теперь строится из системной папки «Документы» и работает с другим именем пользователя.
- В сборку SharedCore включены пропущенные `Contracts/RuntimeEventEnvelope.cs` и `Runtime/VisualEventQueue.cs`.
- Сборка OBS принимает пути к CMake и внешнему дереву OBS параметрами.
- Исправлены путь к Inno Setup и каталог DLL для нативного установщика.
- В `FortuneOracle` неподдерживаемая в .NET Framework перегрузка `String.Replace` заменена на удаление текста через `Regex.Replace` без учёта регистра.
- Демонстрационный оверлей изображений использует картинку из `Assets`, а не файл из личного кэша автора.

## Подключение DonationAlerts и MemeAlerts

Сначала установи [коннекторы](https://github.com/Kiwunaka/streamer.bot-donationAlerts) и отдельно настрой их Connect/Start/Stop. [Инструкция MemeAlerts](https://github.com/Kiwunaka/streamer.bot-donationAlerts/blob/main/docs/MEMEALERTS.md).

`AiDonationHandler.cs` ожидает аргументы `userName`, `amount`, `currency`, `message`. Создай действие `AI | Donation`, вставь туда этот скрипт. В действии-обработчике коннектора перед его вызовом добавь **Core → Arguments → Set Argument**:

| Аргумент для AI | В `DonationHandler_Default` | В `MemeAlerts_Donation` |
| --- | --- | --- |
| `userName` | `%daDonationUsername%` | `%maDonationUsername%` |
| `amount` | `%daDonationAmount%` | `%maDonationAmount%` |
| `currency` | `%daDonationCurrency%` | `%maDonationCurrencyName%` |
| `message` | `%daDonationMessage%` | `%maDonationMessage%` |

Затем добавь **Run Action → AI | Donation**. Для полного AI-сценария заполни `OpenRouterKey` и `ElevenLabsKey`: текущий `AiDonationHandler` проверяет оба ключа до выполнения, даже если в нём есть запасной вызов Inworld. Самостоятельное действие `InworldTTS` имеет другую маршрутизацию и не снимает это требование.

`maDonationType=coins` означает мемкоины: не считай такую сумму рублями. Для мемов используй отдельное действие `MemeAlerts_Sticker` и аргументы `maStickerName`, `maStickerSenderName`, `maStickerPrice`, `maStickerType`. Цена мема указана в мемкоинах. Для покупки пака используй `MemeAlerts_CoinPurchase`: число монет и уплаченная денежная сумма у него передаются отдельно.

## Границы проверки

Нативная DLL успешно собрана MSVC 2022 с внешними зависимостями OBS/Qt. SharedCore собран с контрактами и очередью. Все 20 inline-файлов Streamer.bot прошли проверку компиляции с Roslyn и .NET Framework; отдельные CPH и args подставлены только для этой проверки. В музыкальной папке `timer.cs` проверяется отдельно.

Компиляция с подставленным CPH не проверяет реальные сигнатуры всех методов Streamer.bot, триггеры, платные API или вывод в OBS. Для работы на эфире нужна ручная настройка действий и проверка по [чеклисту](06_Чеклист_перед_эфиром.md).

Dashboard помечен устаревшим в исходных правилах проекта. TwitchHivemind и идеи интеграции PointAuc из старых заметок в этой поставке не реализованы. Датированные отчёты моделей сохранены как история; исходные результаты бенчмарков, на которые они ссылаются, в полученной папке отсутствуют.
