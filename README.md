# Streamer OS

Наработки для стрима на **Streamer.bot + OBS Studio**: AI-персоны, реакции на донаты, озвучка, модерация, генерация изображений, зрительские мини-игры и собственный OBS runtime с аудиовизуализатором.

## Запуск

1. [Быстрый старт](01_Документация/01_Быстрый_старт.md).
2. [Настройка OBS](01_Документация/02_Настройка_OBS.md).
3. [Настройка Streamer.bot](01_Документация/03_Настройка_Streamer_bot.md).
4. [Ключи и провайдеры](01_Документация/04_Ключи_и_маршрутизация.md).
5. [Карта модулей, ограничения и подключение донатных сервисов](01_Документация/07_Карта_проекта.md).

Это исходники и ресурсы. Готового экспорта действий Streamer.bot в исходной папке нет: действия и триггеры создаются вручную. OBS DLL собирается отдельно; инструкции сборки и установки находятся в документации.

Streamer.bot управляет логикой; OBS-плагин принимает визуальные события по `http://127.0.0.1:1608/events`. Основной путь запуска — нативный плагин. Python/Lua-сервер из AudioViz использует те же порты: одновременно их не запускай.

## DonationAlerts и MemeAlerts

Коннекторы живут отдельно: [streamer.bot-donationAlerts](https://github.com/Kiwunaka/streamer.bot-donationAlerts). Для MemeAlerts есть [инструкция получения ключей и подключения](https://github.com/Kiwunaka/streamer.bot-donationAlerts/blob/main/docs/MEMEALERTS.md).

Как передать их события в `AiDonationHandler` — [в карте проекта](01_Документация/07_Карта_проекта.md#подключение-donationalerts-и-memealerts). Копировать код коннекторов в этот репозиторий не нужно.

## Перед использованием

- Для inline-скриптов с `"""` требуется компилятор с поддержкой C# 11. Каждый `CPHInline` — отдельное поддействие Execute C# Code.
- Ключи провайдеров заполняются локально в постоянных глобальных переменных Streamer.bot. Запускай `InitGlobals` с `force=false`, чтобы сохранить заполненные значения.
- Google service-account файл `Assets/google_key.json` исключён из репозитория. При необходимости сохрани свой ключ локально; текущий `generate_intros.py` использует `OPENROUTER_API_KEY` из окружения.
- Исходники OBS, Qt, установщики инструментов, готовые EXE/DLL и каталоги сборки не включены. Для сборки нужны внешние зависимости, описанные в [README_BUILD](03_OBS_и_аудио/01_Плагин_OBS/obs-plugin/README_BUILD.md).
- Настройки моделей и отчёты за 2 апреля 2026 года сохранены как прежние наработки. Доступность этих моделей на текущую дату не подтверждена; укажи доступные модели своего провайдера.
- Старый [AudioViz](https://github.com/Kiwunaka/AudioViz) остаётся отдельным проектом. Здесь сохранена более широкая версия с нативным runtime и логикой Streamer.bot.
